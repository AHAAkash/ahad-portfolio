# Ahad Hosen Akash: portfolio
React + Vite + Tailwind CSS v4 + Framer Motion

    npm install
    cp .env.template .env   # add EmailJS keys for the contact form
    npm run dev
    npm run build           # output in dist/

- Edit your content in `src/data.js`.
- Add your photo as `public/avatar.png` (a transparent PNG looks best) and your CV as `public/Resume.pdf`.
- Needs Node 20.19 or newer (Vite 7).
